How to Deploy

        

          
1. Supabase — create project, run supabase/migrations/0001…0003 in order.

          
2. Vercel — import repo, set Root Directory = backend. Build command npm run build, output public is auto-configured.

          
3. Add env vars: GROQ_API_KEY, SUPABASE_URL, SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY

          
4. Verify: curl https://your-domain/api/health?deep=1 | jq .checks — both must be ok.
