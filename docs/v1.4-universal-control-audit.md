## Phase 2 — AppCapabilityRegistry — **IMPLEMENTED**

`automation/AppCapabilityRegistry.kt`: data-driven categories (messaging / media /
browser / financial) × capabilities (action, support level, strategy, honest
reason). Any package — known or unknown — resolves to a truthful capability set;
unknown apps get launch + generic semantic automation only. Unit-tested.

## Phase 3 — Universal accessibility actions — **PARTIAL**

IMPLEMENTED: click, long-click, type, **clear text (new)**, scroll, swipe,
**focus (new)**, back, home, recents, **open notification shade (new)**, screen
reading, **visible UI summary (new)**. Package verification before WhatsApp
flows; tap/type blocked inside financial apps (fail-safe).
NOT DONE on device: node-level "select" (text-selection semantics) — rare in
real commands; recorded as PARTIAL.

## Phase 4 — Screen understanding — **IMPLEMENTED**

`accessibility/ScreenState.kt` + service collector: package, title, bounded
visible text, buttons, inputs, lists, focused element. Safety is in the MODEL:
password nodes never captured, OTP-like codes redacted, financial screens
flagged+emptied. JVM-tested (7 cases).

## Phase 5 — App-agnostic commands — **IMPLEMENTED (PARTIAL: multi-match asks via message, not picker)**

"এটা press করো", "Send button press koro", "লগইন বাটন চাপো", "লেখাটা মুছো",
"নিচে scroll করো" (v1.1), "back যাও" (v1.1), "বাটন দেখাও" (summary). Targets
resolve from the CURRENT screen state; zero matches and ambiguous matches both
STOP and list the candidates ("…নির্দিষ্ট করে বলুন: Send, Send Money") — never
guessed. A dedicated multi-choice picker dialog is future polish; today the ask
is via message + retry.

## Phase 6 — Camera / Gallery — **ANDROID-LIMITED**

Open camera photo/video/capture-flow: IMPLEMENTED (explicit command only;
shutter always the user's). Gallery open: IMPLEMENTED. Media find/select/share:
**UNSUPPORTED** — Android's photo/file pickers are activity-result flows that a
background assistant cannot complete reliably; stated in-app instead of faked.

## Phase 7 — File management — **ANDROID-LIMITED / UNSUPPORTED**

Open Files app: IMPLEMENTED. open/search/read/rename/move/delete of arbitrary
files: **UNSUPPORTED** — SAF document interactions need an activity result and
per-action user presence; delete-with-confirmation especially cannot be done
safely from the background. Honest in-app. Private app storage: never touched.

## Phase 8 — Notifications — **IMPLEMENTED (reply UNSUPPORTED)**

Summary (banking skipped, OTP redacted) · open source app ("notification er app
khulo", ordinal supported) · notification shade open. Reply: **UNSUPPORTED** —
no reliable per-app RemoteInput route; stated clearly.

## Phase 9 — Device control — **IMPLEMENTED**

Torch (direct), volume up/down/mute (direct), brightness/DND/Wi-Fi/BT/display/
sound + NEW notification-settings / app-settings / accessibility-settings
screens. Android restrictions respected — never bypassed.

## Phase 10 — Conversational context — **IMPLEMENTED**

ContextMemory: app/chat/contact chain with pronouns, 5-min TTL, RAM-only,
contact cleared after send. Unit-tested.

## Phase 11 — Multi-step execution — **IMPLEMENTED**

Plans validate every step; failure STOPS the plan; risky steps confirm at the
correct point; cancelling one step cancels the rest.

## Phase 12 — Financial boundary — **BLOCKED (as required)**

LEVEL 1 open/navigate allowed; LEVEL 2 secrets never touched; LEVEL 3
transactions always refused (fixed Bangla message, no confirmation offered).
Transaction patterns cover bn/banglish/en including "taka send". Unit + mirror
verified.

## Phase 13 — Background reliability — **PARTIAL (code-audited, device QA pending)**

Code-audited: wake service cancels jobs before re-listening (no duplicate
listeners), recognizers destroyed in `finally`, foreground mic session with
visible notification, battery-optimization settings link exists. Device QA
pending: OEM process kills, reboot (no BOOT receiver by design — the user
starts NUVA once after reboot), Doze behaviour.

## Phase 14 — Performance — **IMPLEMENTED (policy) / PARTIAL (measurement)**

Local parser first (Groq only when it cannot understand); no audio ever leaves
the device (transcript text only); bounded screen walks (≤160 nodes, capped
text); caches for installed apps. Battery/memory MEASUREMENTS pending device QA.
