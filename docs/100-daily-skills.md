# NUVA v1.9 — 100 sourced daily-life skills

Every skill below is a read-only shortcut to a current web source. NUVA preserves details from the
command (for example a parcel code or destination), opens a search, and never treats changing facts
as model knowledge. Money transfer/payment automation and credentials are rejected before this
registry runs.
