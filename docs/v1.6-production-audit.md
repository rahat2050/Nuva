## 2. Defect sweep results

* **TODO/FIXME/placeholder code: none** (all grep hits were the `CREATE_TODO` feature and a Compose `placeholder` param).
* **Fake success paths: none** — every execution returns status+speech from the real outcome; WhatsApp send verifies recipient first.
* **Dead/duplicate code: none material** — `CommandParser.OfflineResult` retained as documented shape (warning-free, harmless).
* **printStackTrace/println/Log: zero** — no sensitive data can leak into logs.
* **Empty catches: zero**; best-effort catches are intentional (network reporting) and annotated.
* **Coroutine leaks:** ViewModel scopes use IO dispatchers without explicit cancellation (fine — VM-scoped); WakeWordService scope cancels jobs before re-listening; the two NEW timeouts close the remaining stuck-session risk.
* **Race conditions:** `planQueue`/`ContextMemory` are single-command-sequential by design (documented); `@Volatile` where the UI reads.
* **Duplicate listeners/services:** guarded via job cancellation + `runCatching` start/stop helpers.
