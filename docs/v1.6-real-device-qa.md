## APK generation — EXACT manual GitHub Actions steps

1. Open **https://github.com/rahat2050/Nuva/actions**
2. Left sidebar → **NUVA APK Mobile Build** (workflow id 341039105 — verified ACTIVE).
3. Button **"Run workflow"** ▾ → Branch: **`arena/01a038d4-nuva`** → click green **Run workflow**.
4. Wait ~5–8 min (SDK install + `assembleDebug`).
   - Green ✓ → open the run → bottom **Artifacts** → download **`nuva-apk`** (zip → `app-debug.apk`).
   - Red ✗ → **Actions → failed run → job log** — paste the Kotlin/compiler error back to the
     agent; only compile/build fixes are in scope (no feature work, per freeze).
5. Install: `adb install app-debug.apk` (or sideload) → begin this guide at A1.

**Why manual:** the CI token used by this environment has no `actions:write` scope (dispatch
returns 403). Per instruction, permissions are NOT bypassed. APK success is claimed only after
step 4 produces the artifact — until then, status is PENDING.
